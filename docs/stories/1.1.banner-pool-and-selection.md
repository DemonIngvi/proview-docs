# Story 1.1: Пул баннеров и выбор по преднастройке

## Status

Done

## Story

**Как** посетитель сайта, **я хочу** получать подходящий баннер для рекламного места за миллисекунды, **чтобы** реклама не замедляет страницу.

## Acceptance Criteria

1. GET /v1/banner?placement=… возвращает креатив места с учётом веса
2. Таргетинг по стране, устройству, периоду; пустой список — без ограничений
3. 204 при отсутствии подходящего, 404 для неизвестного места, 400 для неверного id
4. Выдача продолжается из последнего снимка при недоступной БД; readiness только после первой загрузки
5. Внутреннее имя баннера не попадает в публичный ответ
