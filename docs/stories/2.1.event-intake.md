## Status

## Story

**Как** SDK на странице, **я хочу** отправлять пакеты событий одним запросом без CORS-preflight, **чтобы** статистика доходит быстро и дёшево.

## Acceptance Criteria

1. POST /v1/events принимает text/plain и application/json до 64 КБ, 1..20 показов по ≤ 50 событий
2. Поддельный или просроченный токен — события отклоняются и считаются в rejected
3. Боты по User-Agent не учитываются
4. Обогащение: страна из заголовка, устройство, хост страницы, время клиента в окне ±5 мин
5. event_id = impression_id:seq
