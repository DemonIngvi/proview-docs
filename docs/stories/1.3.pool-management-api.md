## Story

**Как** трафик-менеджер, **я хочу** заводить и менять баннеры и места через API, **чтобы** менять ротацию без выкладки кода.

## Acceptance Criteria

1. CRUD баннеров и upsert мест под Bearer-токеном на отдельном порту
2. Пустой настроенный токен закрывает API полностью
3. Валидация: URL, вес 1..10000, размеры, страны ISO, устройства, существующие места, ends_at > starts_at
4. Изменение видно в выдаче без перезапуска
5. Удаление — мягкая деактивация
