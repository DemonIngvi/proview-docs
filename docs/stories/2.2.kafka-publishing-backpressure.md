1. Идемпотентный продюсер acks=all, ключ impression_id сохраняет порядок
2. Буфер выше 90 % лимита → 503 + Retry-After и readiness false
3. При остановке буфер сбрасывается в Kafka
4. SASL/TLS настраиваются переменными
