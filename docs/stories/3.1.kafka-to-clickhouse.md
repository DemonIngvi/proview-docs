# Story 3.1: Загрузка Kafka → ClickHouse ровно один раз

## Status

Done

## Story

**Как** аналитик, **я хочу** чтобы каждое принятое событие попало в хранилище ровно один раз, **чтобы** цифры совпадают с реальностью.

## Acceptance Criteria

1. Пачки по размеру или времени, коммит смещений только после успешной вставки
2. Повтор вставки с тем же токеном, токен не зависит от порядка записей
3. ClickHouse отбрасывает повтор пачки в raw и в агрегатах
4. Невалидные сообщения уходят в DLQ, поток не останавливается
5. Простой ClickHouse и SIGKILL загрузчика не теряют и не удваивают события
