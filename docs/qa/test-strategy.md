# ProView — Test Strategy & Results

> BMAD Method · артефакт QA · версия 1.0 · 2026-11-06

## 1. Пирамида

| Уровень | Где | Инструмент | Что проверяет |
|---|---|---|---|
| Unit | каждый репозиторий | `go test -race`, `node --test` | доменная логика без I/O (выбор, токен, валидация, батчинг, SQL-построитель, трекер SDK, очередь) |
| Контрактные | collector ↔ banner-service, ingester ↔ collector, analytics ↔ ingester | контрольные векторы, копия схемы в `testdata` | совместимость форматов между репозиториями |
| Интеграционные | сервис + настоящая зависимость (`-tags integration`) | Postgres 17, Kafka 4.1, ClickHouse 25.8 (services в CI) | миграции, SQL, порядок в партиции, дедупликация и MV |
| E2E | proview-deploy | Go (`-tags e2e`) против docker compose | путь браузер → аналитика, таргетинг, антифрод |
| Chaos | proview-deploy | `scripts/chaos.sh` | отказ ClickHouse, SIGKILL загрузчика: ровно один раз |
| Нагрузка | proview-deploy | k6 | RPS, латентность, ошибки, успевает ли загрузка |
| Статический анализ | каждый репозиторий | golangci-lint v2 (gosec, errorlint …), helm lint, kubeconform (+ схемы CRD), Trivy | качество, безопасность, валидность манифестов |
| Визуальная проверка | админка | headless Chromium | вёрстка, темы, мобильная ширина |

## 3. Дефекты, найденные тестами и исправленные

| Где | Дефект | Как найден | Исправление |
|---|---|---|---|
| analytics | неполная первая минута периода не попадала в срез | chaos-тест (нулевая базовая линия) | начало интервала округляется до бакета, unit-тест `TestFromIsFlooredToBucket` |
| analytics | параметр `limit` конфликтовал с серверной настройкой ClickHouse | интеграционный тест | переименован в `row_limit` |
| analytics | подключение к ещё не созданной БД `proview_agg` | интеграционный тест | подключение к `default`, полные имена таблиц |
| web | 502 при 2k+ RPS: исчерпание эфемерных портов в прокси | k6 | upstream keepalive-пулы с `resolve`, свой `nginx.conf` |
| analytics UI | обрезанные подписи, нет шкалы тепловой карты | скриншоты | правка отступов и легенды |

## 4. Как запустить

```bash
# в репозитории сервиса
make test
make test-integration           # переменные PROVIEW_TEST_* — см. README
npm test                        # proview-web, proview-analytics
# платформа
cd proview-deploy && make e2e && make chaos && make load RPS=5000 DURATION=2m
```

## 5. Критерии выпуска

1. CI каждого сервиса зелёный: lint, unit, integration, helm, образ, Trivy без CRITICAL и HIGH с исправлениями.
2. Ночной прогон proview-deploy (e2e, chaos, k6 1k RPS) зелёный на main-ветках всех сервисов.
3. При изменении контракта обновлены контрольные векторы на обеих сторонах.
4. Нагрузочный прогон в стейджинге на целевых 20k RPS: p95 < 50 мс, ошибки < 0,1 %, лаг загрузки не растёт.
